# دليل المالية

## لمن هذا الدليل

لموظفي **قسم المالية في المقر**: استلام النقد من المشرفين وعدّه، إدارة صندوق المالية والمصرف، تسليم أمانة دائرة الماء،
دفتر الحساب، الفروقات، صيغة الـ35%، الفواتير السابقة، اعتماد الرواتب وصرفها، ومصاريف الموظفين.

## أول دخول

1. اكتب **رقم الموظف (ID)** و**كلمة المرور** ثم اضغط **تسجيل الدخول**.
2. الجهاز الجديد يظهر عليه **جهاز جديد بانتظار الاعتماد**. أعطِ الإدارة التقنية رقمك و**رمز الجهاز**. الموافقة مرة واحدة فقط.
3. الجهاز المعتمد لا يُستخدم لحساب آخر. عدد الأجهزة لكل حساب محدود.
4. يُسجَّل خروج الجميع **كل يوم عند منتصف الليل**.

## أقسام البوابة

| القسم | الغرض |
|---|---|
| **اليوم** | تحصيل اليوم والشهر، دخل الشركة، أمانة دائرة الماء، **أين النقد الآن** (لدى الجباة، لدى المشرفين، صندوق المالية، المصرف). |
| **استلام النقد** | المشرفون الذين لديهم نقد للتسليم، وزر **استلام وعدّ**، و**سجل الاستلام**. |
| **الصندوق والمصرف** | **صندوق المالية (نقد في المقر)** و**المصرف**، مع **إيداع في المصرف** و**سحب إلى الصندوق**. |
| **أمانة دائرة الماء** | المحفوظ لدينا من مال الدائرة، وزر **تسليم للدائرة**، و**سجل التسليم**. |
| **دفتر الحساب** | **الحسابات** (دخل / خرج / فيه الآن) و**التصحيحات اليدوية**. |
| **الفروقات** | فروقات الجباة التي أحالها المشرفون، وفروقات المشرفين عند العدّ في المقر. |
| **الأداء والتعادل** | هل يغطي كل جابٍ كلفته اليومية. |
| **صيغة الـ35%** | حصة الشركة من الزيادة: إيرادات 2025 (الأساس) والخياران (أ) و(ب)، و**طلب التسوية**. |
| **الفواتير السابقة** | **رفع ملف دائرة الماء** (Excel أو CSV)، مراجعته، ثم **اعتماد الملف**. |
| **التنبؤ** | المتوقع لنهاية الشهر. |
| **كشف التلاعب** | درجات المخاطر والحالات الشاذة وتحليل الأرقام. |
| **المتأخرات** | أعمار المتأخرات. |
| **الرواتب** | **اعتماد (المالية)** لرواتب الشهر، ثم **تسجيل الصرف**. |
| **مصاريف الموظفين** | **موافقة** أو **رفض** مطالبات المصاريف مع صورة الوصل. |

**ملاحظة:** أمانة دائرة الماء **ليست دخلاً للشركة وليست ديناً عليها**. نحفظها ونسلّمها للدائرة.
الربح ودخل الشركة التفصيلي يراه المالك فقط.

## المهام اليومية

### 1. استلام نقد المشرف (عدّ أعمى)
1. افتح **استلام النقد**. ترى من لديه نقد، ولا ترى المبلغ.
2. اضغط **استلام وعدّ** أمام المشرف وهو حاضر.
3. عُدّ النقد، واكتب عدد الأوراق من كل فئة، ثم اضغط **حفظ العدّ**.
4. بعد الحفظ فقط يظهر المبلغ المفروض: **مطابق تماماً** أو **نقص** أو **زيادة**.
5. عند وجود فرق اضغط **قرار** واختر:
   - للنقص: **دفع المشرف النقص الآن نقداً** أو **يُخصم من راتب المشرف** أو **شطب النقص (خسارة)**.
   - للزيادة: **تُسجّل الزيادة إيراداً للشركة** أو **شطب الزيادة**.
6. اكتب **السبب (إلزامي)** ثم **تأكيد**. الشطب فوق الحد المسموح ينتظر موافقة المالك.

### 2. الصندوق والمصرف
1. افتح **الصندوق والمصرف**.
2. لإيداع النقد اضغط **إيداع في المصرف**، واكتب **المبلغ** و**رقم الوصل المصرفي (اختياري)**، ثم **تسجيل**.
3. للسحب اضغط **سحب إلى الصندوق** بنفس الطريقة.

### 3. تسليم أمانة دائرة الماء
1. افتح **أمانة دائرة الماء** واضغط **تسليم للدائرة**.
2. اختر **من المصرف** أو **نقداً من الصندوق**.
3. اكتب **المبلغ** و**رقم الحوالة أو وصل الاستلام**، ثم **تسجيل التسليم**.

### 4. معالجة الفروقات
1. افتح **الفروقات**. لكل فرق جابٍ محال: **خصم النقص من راتب الجابي** أو **شطب الفرق**.
2. فروقات المشرفين تُقرَّر من **استلام النقد** (زر **قرار**).

### 5. التصحيحات اليدوية
1. في **دفتر الحساب** افتح **التصحيحات اليدوية** واضغط **تصحيح جديد**.
2. اختر **نوع التصحيح**: عمولة مصرفية، مصروف نقدي من الصندوق، تسديد الضرائب والضمان المستقطعة، رصيد افتتاحي للصندوق أو للمصرف.
3. اكتب **المبلغ** و**السبب / البيان**، ثم **تسجيل**. التصحيح الكبير ينتظر موافقة المالك.
4. لا يُحذف تصحيح. للإلغاء اضغط **عكس القيد**، فيُسجَّل تصحيح معاكس بتاريخ اليوم.

### 6. الرواتب والمصاريف (نهاية الشهر)
1. تحتسب الموارد البشرية الرواتب كـ**مسودة**.
2. افتح **الرواتب**، راجع الأرقام، ثم اضغط **اعتماد (المالية)**. بعدها لا يمكن إعادة الاحتساب، وتظهر القسائم للموظفين.
3. بعد الدفع اضغط **تسجيل الصرف** واختر **نقداً من صندوق المالية** أو **تحويل من المصرف**.
4. في **مصاريف الموظفين** افتح **الوصل** لكل مطالبة، ثم **موافقة** أو **رفض**. المصروف المعتمد يُدفع مع الراتب القادم.

### 7. صيغة الـ35% والفواتير السابقة (حسب الحاجة)
1. في **صيغة الـ35%** أدخل **إيرادات 2025 (الأساس)** لكل شهر (**إدخال** / **تعديل**).
2. بعد انتهاء الشهر اضغط **طلب التسوية**. يُرسل الطلب إلى المالك للموافقة.
3. في **الفواتير السابقة** اضغط **اختيار ملف ورفعه**. يجب أن يحوي الملف عمود **المبلغ**، ومعه رقم الحساب أو رقم العداد أو الهاتف.
4. راجع الصفوف (**مكررة**، **بلا عقار**، **مبلغ غير معتاد**)، استعمل **ربط الصف بعقار** أو **تصحيح المبلغ**، ثم **اعتماد الملف**. لا يمكن التراجع بعد الاعتماد.

## عند حدوث مشكلة

| الرسالة | المعنى وما تفعله |
|---|---|
| لا يوجد نقد مستلم من الجباة بانتظار التسليم لدى هذا المشرف | المشرف لم يُغلق صناديق جباته بعد. |
| بقيت ... مطابقات لم يعالج المشرف فروقاتها بعد | هذا النقد لم يُسلَّم. يعالجها المشرف أولاً. |
| مجموع الأوراق النقدية لا يساوي المبلغ المدخل | أعد كتابة عدد الأوراق. |
| الرصيد لا يكفي / لا يكفي الرصيد في ... | المبلغ أكبر من رصيد الصندوق أو المصرف. |
| المبلغ أكبر من أمانة دائرة الماء المحفوظة | لا تسلّم أكثر من الأمانة الموجودة. |
| الحساب «...» يُحسب تلقائياً من العمل الميداني ولا يقبل تصحيحاً يدوياً | لا تصحح هذا الحساب يدوياً. |
| لا يمكن تسجيل تصحيح بتاريخ مستقبلي | اختر تاريخ اليوم أو قبله. |
| يجب اعتماد الرواتب قبل الصرف | اضغط **اعتماد (المالية)** أولاً. |
| الرواتب معتمدة مسبقاً | لا حاجة لاعتماد آخر. |
| أدخل إيرادات .../2025 أولاً | أدخل الأساس لنفس الشهر قبل طلب التسوية. |
| لا تُسوّى إلا الأشهر المنتهية | انتظر انتهاء الشهر. |
| لم يُعثر على عمود المبلغ | سمّ العمود «المبلغ» في الملف. |
| يوجد عقار مكرر في الملف | تخطَّ أحد الصفين أو صحّح الربط ثم اعتمد. |

## القواعد

1. **عُدّ أولاً** دائماً، وأمام المشرف. لا تطلب المبلغ المتوقع قبل حفظ العدّ.
2. أمانة دائرة الماء ليست دخلاً للشركة. لا تصرف منها.
3. لا تحذف ولا تعدّل القيود. التصحيح يكون بقيد معاكس فقط.
4. الشطب والتصحيح فوق الحد المسموح يحتاج موافقة المالك.
5. لا تعتمد الرواتب قبل مراجعة المسودة، فالاعتماد نهائي.
6. لا تعتمد مصروفاً دون صورة وصل واضحة.
