# دليل الموارد البشرية

## لمن هذا الدليل

لموظفي **الموارد البشرية**: ملفات الموظفين، الحضور، الإجازات، احتساب الرواتب، المصاريف، التقييم، العهد، التوظيف، والتدريب.

## أول دخول

1. اكتب **رقم الموظف (ID)** و**كلمة المرور** ثم اضغط **تسجيل الدخول**.
2. الجهاز الجديد يظهر عليه **جهاز جديد بانتظار الاعتماد**. أعطِ الإدارة التقنية رقمك و**رمز الجهاز**. الموافقة مرة واحدة فقط.
3. الجهاز المعتمد لا يُستخدم لحساب آخر.
4. يُسجَّل خروج الجميع **كل يوم عند منتصف الليل**.

## أقسام البوابة

| القسم | الغرض |
|---|---|
| **لوحة القيادة** | موظف فعال، حاضر اليوم، متأخر اليوم، غائب من الميدان، في إجازة، إجازات بانتظار الموارد، مصاريف معلقة، عهد لدى الموظفين، آخر رواتب، والعقود والوثائق التي تنتهي خلال 30 يوماً. |
| **الموظفون** | البحث في الموظفين، **موظف جديد**، وفتح **ملف الموظف**. |
| **الحضور** | حضور اليوم: حاضر / متأخر / غائب / إجازة، مع **سيلفي الحضور** والتنبيه **خارج القاطع**. |
| **الإجازات** | طلبات الإجازة: **اعتماد** أو **رفض**. |
| **الرواتب** | **احتساب** رواتب الشهر كمسودة، و**إعادة احتساب** قبل اعتماد المالية. |
| **المصاريف** | مطالبات المصاريف مع صورة الوصل: **موافقة** أو **رفض**. |
| **التقييم** | **احتساب التقييم التلقائي** الشهري. |
| **العهد** | العهد لدى الموظفين، و**تسوية** (أُعيدت / مفقودة). |
| **التوظيف** | **وظيفة شاغرة جديدة**، **إضافة متقدم**، **نقل إلى مرحلة**، و**تعيين**. |
| **التدريب** | **دورة جديدة**، **إسناد لموظفين**، **تسجيل الإكمال**. |

في **ملف الموظف**: **تعديل**، **وثيقة**، **تسليم عهدة**، **إجراء انضباطي**، **إنهاء الخدمة** أو **إعادة تفعيل**.

## المهام اليومية

### 1. متابعة الحضور
1. افتح **لوحة القيادة** لترى الأرقام العامة.
2. افتح **الحضور**. راجع المتأخرين والغائبين، وافتح **صورة الحضور** عند الشك.
3. الحضور المسجّل **خارج القاطع** يحتاج متابعة مع المشرف.

### 2. البت في الإجازات
1. افتح **الإجازات** واختر **بانتظار القرار**.
2. اقرأ النوع والمدة والسبب، وافتح **المرفق** إن وجد.
3. اضغط **اعتماد** أو **رفض**.
4. القرار للموارد البشرية فقط. المشرف يطّلع على إجازات فريقه ولا يقررها، ولا يمكنك البت في طلب إجازتك أنت.

### 3. إضافة موظف أو تعديل ملفه
1. افتح **الموظفون** واضغط **موظف جديد**.
2. املأ **رقم الموظف (مثال JB-0500)**، **الاسم الكامل**، **الدور**، **كلمة المرور** (8 أحرف على الأقل)، **القاطع**، **المشرف المباشر**، **الراتب الأساسي** والبدلات، و**الهدف اليومي للتحصيل (للجباة)**.
3. اضغط **إنشاء الموظف**.
4. أخبر الموظف أن جهازه يحتاج موافقة الإدارة التقنية عند أول دخول.

### 4. الرواتب (نهاية الشهر)
1. افتح **الرواتب**، واختر **الشهر**، واضغط **احتساب**.
2. راجع المسودة: الإجمالي، الاستقطاعات، الصافي، العمولات.
3. إذا تغيّر شيء (حضور، إجازة، خصم) اضغط **إعادة احتساب**.
4. المسودة تُعتمد من قسم المالية. بعد الاعتماد لا يمكن إعادة الاحتساب.

### 5. المصاريف والعهد
1. في **المصاريف** افتح **الوصل** لكل مطالبة، ثم **موافقة** أو **رفض**. المعتمد يُدفع مع الراتب القادم.
2. لتسليم عهدة افتح ملف الموظف واضغط **تسليم عهدة** (النوع، الوصف، الرقم التسلسلي، القيمة).
3. عند إعادتها أو فقدانها اضغط **تسوية**. للمفقودة يمكن **خصم القيمة من الراتب**.

### 6. الانضباط وإنهاء الخدمة
1. من ملف الموظف اضغط **إجراء انضباطي**، واختر **نوع الإجراء**، واكتب **السبب (إلزامي)**.
2. الإيقاف يوقف حساب الموظف فوراً.
3. عند تكرار الإنذارات الكتابية خلال 12 شهراً يظهر تنبيه بأنه يُنصح بالإيقاف.

## عند حدوث مشكلة

| الرسالة | المعنى وما تفعله |
|---|---|
| رقم الموظف مستخدم مسبقاً | اختر رقماً آخر. |
| رقم الهاتف غير صالح | اكتب الرقم بصيغة 07... |
| إنشاء حسابات القيادة متاح لمدير النظام فقط | حسابات القيادة والإدارة تُنشأ من الإدارة التقنية. |
| لا يمكنك البت في طلب إجازتك | يبت فيه موظف آخر في الموارد البشرية. |
| تمت معالجة الطلب مسبقاً | الطلب حُسم من قبل. |
| تم اعتماد رواتب هذا الشهر، لا يمكن إعادة الاحتساب | الرواتب نهائية بعد اعتماد المالية. |
| اعتماد وصرف الرواتب من صلاحية المالية | دورك الاحتساب فقط. |
| لا يمكن إنهاء الخدمة: بحوزته ... عهدة | سوِّ العهد أولاً. |
| لا يمكن إنهاء الخدمة: لديه وصولات لم تُسلَّم نقودها للمشرف | يجب أن يطابق المشرف نقده أولاً. |
| الموظف غير فعال مسبقاً | الحساب موقوف أو منتهٍ. |

## القواعد

1. الإجازات تقررها الموارد البشرية فقط، ولا يقرر الموظف في طلبه.
2. الرواتب: الموارد البشرية تحتسب، والمالية تعتمد وتصرف.
3. لا تنهِ خدمة موظف بحوزته عهدة أو نقد غير مسلَّم.
4. لا تُنشئ حساباً بكلمة مرور سهلة، واطلب من الموظف عدم مشاركتها.
5. علّم الجباة الجدد القاعدتين: لا رمز إلا ما يقرأه المواطن، ولا مبلغ أكثر من الفاتورة.
