# دليل المالك

## لمن هذا الدليل

لمالك الشركة. **لوحة المالك** تعطيه صورة يومية سريعة، والربح والخسارة، والموافقة على الطلبات التي تتجاوز الحد المسموح،
وتغيير الإعدادات التي سمحت له بها الإدارة التقنية.

## أول دخول

1. اكتب **رقم الموظف (ID)** و**كلمة المرور** ثم اضغط **تسجيل الدخول**.
2. الجهاز الجديد يظهر عليه **جهاز جديد بانتظار الاعتماد**. أعطِ الإدارة التقنية رقمك و**رمز الجهاز**. الموافقة مرة واحدة لكل جهاز.
3. عدد الأجهزة المسموح لحسابك محدود (الافتراضي جهازان). الجهاز المعتمد لا يُستخدم لحساب آخر.
4. يُسجَّل خروج الجميع **كل يوم عند منتصف الليل**.

## أقسام البوابة

| القسم | الغرض |
|---|---|
| **يومي** | المحصّل اليوم، وصولات اليوم، دخل الشركة اليوم مقارنة بنفس اليوم قبل 4 أسابيع، **نقد خارج المقر**، استخدام الرمز الرئيسي اليوم، فروقات نقدية مفتوحة، استغاثات مفتوحة، من **لم يبدأوا اليوم**، كلفة **واتساب هذا الشهر**، ونتائج **الاتصال العشوائي بالمواطنين**. |
| **الملخص** | ربح هذا الشهر حتى الآن، دخل الشركة، نقد الشركة الآن، أمانة دائرة الماء المحفوظة، **نقطة التعادل (وصولات الشهر)**، آخر 6 أشهر، دخل الشركة حسب المصدر وحسب القاطع. |
| **الموافقات** | الطلبات التي تنتظر موافقتك: **تصحيح يدوي**، **شطب جابي**، **شطب مشرف**، **تسوية صيغة الـ35%**. |
| **الربح والخسارة** | ما دخل للشركة، وما صرفته، والربح أو الخسارة للشهر. أمانة دائرة الماء تظهر منفصلة (ليست ضمن الربح). |
| **الأداء والتعادل** | كلفة كل جابٍ اليومية مقابل ما يكسبه للشركة. |
| **صيغة الـ35%** | حصة الشركة من الزيادة، والخياران (أ) و(ب). |
| **التحصيل** | نظرة التحصيل نفسها التي تراها المالية. |
| **كل الحسابات** | دفتر الحساب كاملاً، بما فيه حسابات الدخل والكلف. |
| **سجل المالية** | كل إجراء قامت به المالية (**اليوم** / **7 أيام** / **30 يوماً**). |
| **كشف التلاعب** | درجات المخاطر والحالات الشاذة. |
| **التنبؤ** | المتوقع لنهاية الشهر. |
| **المتأخرات** | أعمار المتأخرات. |
| **إعداداتي** | الإعدادات التي تستطيع تغييرها بنفسك. |

## ما تراه أنت فقط

- حسابات دخل الشركة والكلف والربح تظهر للمالك فقط. المالية ترى أين النقد، والأمانة، وما يدين به الموظفون.
- الشطب والتصحيحات اليدوية فوق الحد المسموح لا تظهر في الحسابات قبل موافقتك.
- الحد المسموح وباقي الإعدادات تحددها الإدارة التقنية، إلا ما سمحت لك بتغييره في **إعداداتي**.

## المهام اليومية

### 1. النظرة الصباحية (5 دقائق)
1. افتح **يومي**.
2. إذا ظهر **فوق الحد المسموح!** تحت **نقد خارج المقر**، فهناك نقد كثير لدى الجباة والمشرفين. اطلب من المالية والقيادة متابعة التسليم.
3. راجع قائمة **لم يبدأوا اليوم**: من لم يُصدر وصلاً وليس في إجازة معتمدة.
4. راجع **مواطنون أنكروا الدفع أو ذكروا مبلغاً مختلفاً**. أي حالة هنا تحتاج متابعة مع القيادة وكشف التلاعب.

### 2. الموافقات
1. افتح **الموافقات**. الشطب والتصحيحات فوق الحد المسموح تنتظرك هنا.
2. اقرأ النوع والمبلغ والسبب ومن طلبه.
3. اضغط **موافقة** أو **رفض**.
4. في **تسوية صيغة الـ35%**: موافقتك تقيّد المبلغ دخلاً للشركة (حصة الزيادة فوق إيرادات 2025).

### 3. متابعة الربح
1. افتح **الملخص** لترى ربح الشهر حتى الآن، ونقطة التعادل: **ضمن المسار** أو **متأخرون عن المسار**.
2. افتح **الربح والخسارة** لتفاصيل الشهر.
3. افتح **الأداء والتعادل** لمعرفة الجباة الذين لا يغطون كلفتهم.

### 4. مراقبة المالية
1. افتح **سجل المالية** واختر الفترة.
2. راجع التصحيحات والشطب وتسليمات الأمانة.

### 5. تغيير إعداداتك
1. افتح **إعداداتي**. تظهر فقط الإعدادات التي سمحت لك بها الإدارة التقنية.
2. اضغط على الإعداد، وأدخل القيمة ضمن الحد الأدنى والأعلى، واكتب **سبب التغيير (اختياري)**، ثم **حفظ**.
3. كل تغيير يُسجَّل باسمك. إذا احتجت إعداداً غير موجود فاطلبه من الإدارة التقنية.

## عند حدوث مشكلة

| الرسالة أو الحالة | المعنى وما تفعله |
|---|---|
| لم تسمح الإدارة التقنية بأي إعداد لك بعد | اطلب من الإدارة التقنية إظهار الإعدادات التي تحتاجها. |
| هذا الإعداد يُغيَّر من الإدارة التقنية فقط | الإعداد ليس ضمن صلاحيتك. |
| أقل قيمة مسموحة / أعلى قيمة مسموحة | أدخل قيمة ضمن الحدود. |
| لا طلبات بانتظار موافقتك | لا يوجد شيء يحتاج قرارك الآن. |
| جهاز جديد بانتظار الاعتماد | أعطِ الإدارة التقنية رمز الجهاز. |
| انتهت الجلسة، يرجى تسجيل الدخول مجدداً | خروج منتصف الليل. ادخل من جديد. |

## القواعد

1. أمانة دائرة الماء ليست دخلاً للشركة، حتى لو كانت في صندوق الشركة أو المصرف.
2. لا توافق على شطب دون سبب مكتوب وواضح.
3. الرسائل المجانية في واتساب بلا كلفة. ارتفاع الرسائل المدفوعة يعني أن الجباة لا يطلبون من المواطن مراسلة رقم الشركة أولاً.
4. ارتفاع استخدام **الرمز الرئيسي** إشارة تحتاج متابعة مع القيادة.
5. قاعدة الجباية للجميع: لا رمز إلا ما يقرأه المواطن، ولا مبلغ أكثر من الفاتورة.
