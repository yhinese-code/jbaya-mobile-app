# دليل المشرف

## لمن هذا الدليل

لمشرف فريق الجباة. المشرف يجبي بنفسه في الميدان أيضاً، ويطابق نقد الجباة، ويراجع الفواتير، ويسلّم النقد إلى قسم المالية في المقر.

## أول دخول

1. اكتب **رقم الموظف (ID)** و**كلمة المرور** ثم اضغط **تسجيل الدخول**.
2. الجهاز الجديد يظهر عليه **جهاز جديد بانتظار الاعتماد**. أعطِ الإدارة التقنية رقمك و**رمز الجهاز**. الموافقة مرة واحدة فقط.
3. حساب المشرف يعمل على **جهاز واحد** فقط، ولا يُستخدم هذا الجهاز لحساب آخر.
4. يُسجَّل خروج الجميع **كل يوم عند منتصف الليل**.

## أقسام البوابة

| القسم | الغرض |
|---|---|
| **عملي الميداني** | جبايتك الخاصة: **التسجيل** و**الجباية** و**وصولاتي** (نفس خطوات الجابي ونفس الحصة). |
| **الفريق** | نشاط كل جابٍ اليوم: الحضور، وصولات اليوم، تسجيلات اليوم، بانتظار التسليم، قيد المراجعة، الرمز الرئيسي. لا يظهر هنا أي مبلغ. |
| **المطابقة النقدية** | عدّ نقد الجابي عدّاً أعمى وإغلاق صندوقه، ومعالجة الفروقات. |
| **مراجعة الفواتير** | الفواتير التقديرية والمحجوبة التي تحتاج قرارك. |
| **الفواتير السابقة** | الفواتير الورقية التي أدخلها الجباة، أو التي تختلف عن ملف دائرة الماء. |
| **التسليم للمالية** | النقد الذي بحوزتك لتسليمه للمالية، وما سلّمته سابقاً. |
| **أداء الفريق** | أداء الجباة بعدد المنازل (دون مبالغ). |
| **الاستغاثات** | نداءات الاستغاثة من الميدان. |
| **حضور الفريق** | حضور اليوم مع صور السيلفي. |
| **إجازات الفريق** | للاطلاع فقط. **الموافقة من صلاحية الموارد البشرية فقط.** |
| **تقييم الفريق** | التقييم الشهري، وإضافة تقييم المشرف بالنجوم. |

في الأعلى أيضاً: **رسائل القيادة** و**خدماتي** (الحضور، الإجازات، الراتب).

## المهام اليومية

### 1. متابعة الفريق صباحاً
1. افتح **الفريق** وتأكد أن كل جابٍ سجّل الحضور.
2. راقب **الاستغاثات**. عند وصول نداء اضغط **استلام والتحرك**، وبعد المعالجة **إغلاق (تمت المعالجة)**.

### 2. الجباية بنفسك
1. افتح **عملي الميداني**.
2. اتبع نفس خطوات الجابي (راجع [دليل الجابي](collector.md)): التسجيل، القراءة، رسالة المواطن، الرمز، الوصل.
3. نقدك الخاص يدخل في تسليمك للمالية تلقائياً.
4. فواتيرك التقديرية يراجعها **مشرف آخر**، وليس أنت.

### 3. المطابقة النقدية العمياء (لكل جابٍ)
1. افتح **المطابقة النقدية** واختر **الجابي**.
2. عُدّ الأوراق النقدية، واكتب **عدد الأوراق** لكل **فئة**. المبلغ المتوقع لا يظهر قبل الإرسال.
3. اضغط **كشف الحساب وإغلاق الصندوق**، ثم **إرسال**. لا يمكن تعديل المطابقة بعد الإرسال.
4. تظهر **النتيجة**: **مطابق** أو **عجز** أو **زيادة**.
5. عند وجود فرق اضغط **معالجة الفرق** واختر:
   - للعجز: **دفع الجابي الفرق نقداً الآن** أو **يُستقطع من راتب الجابي**.
   - للزيادة: **يُودَع الفائض ويُحقَّق في مصدره**.
   - للحالتين: **إحالة إلى القيادة للتحقيق**.
6. اكتب **التفاصيل (إلزامي)** ثم **تأكيد**.

### 4. مراجعة الفواتير
1. افتح **مراجعة الفواتير**. قارن **صورة العداد** و**قراءة الكاميرا (OCR)** بالقراءة المكتوبة.
2. اختر:
   - **موافقة** (الموافقة على التقدير).
   - **عداد مُبدَّل (أساس جديد)**: عندما تكون القراءة أقل من السابقة لأن العداد تغيّر.
   - **رفض**.
3. اكتب **السبب / الملاحظة (إلزامي)**.

### 5. مراجعة الفواتير السابقة
1. افتح **الفواتير السابقة**. قارن **صورة الفاتورة الورقية** بالمبلغ.
2. للإدخال الميداني: **اعتماد** أو **رفض**.
3. عند الاختلاف مع ملف الدائرة: **اعتماد مبلغ الورقة** أو **إبقاء مبلغ الملف**.
4. لا يمكنك مراجعة فاتورة أدخلتها أنت.

### 6. التسليم للمالية
1. عالج كل الفروقات أولاً في **المطابقة النقدية**.
2. افتح **التسليم للمالية** لترى **النقد بحوزتك لتسليمه للمالية** (من الجباة ومن جبايتك).
3. احمل النقد إلى **قسم المالية في المقر**. المالية تعدّه أمامك دون أن ترى المبلغ المتوقع، وأي فرق يُسجَّل باسمك.
4. يظهر التسليم في **ما سلّمته للمالية** مع أي نقص أو زيادة.

## عند حدوث مشكلة

| الرسالة | المعنى وما تفعله |
|---|---|
| لا توجد وصولات غير مسواة لهذا الجابي | لا يوجد نقد لمطابقته عند هذا الجابي. |
| مجموع الأوراق النقدية لا يساوي المبلغ المدخل | راجع عدد الأوراق في كل فئة. |
| تمت معالجة هذه المطابقة مسبقاً | الفرق عولج. لا تُعِد العدّ. |
| هذا الإجراء لا يناسب نوع الفرق | مثلاً الاستقطاع من الراتب للعجز فقط. |
| لديك ... فروقات لم تعالجها بعد | عالجها في **المطابقة النقدية** قبل الذهاب للمقر. |
| لم يعد الإيداع في المصرف متاحاً للمشرف | لا إيداع في المصرف. سلّم النقد للمالية في المقر. |
| الموافقة متاحة فقط لفواتير التقدير | هذه الفاتورة ليست تقديرية. |
| إعادة تعيين الأساس متاحة فقط عندما تكون القراءة أقل من السابقة | استعمل **عداد مُبدَّل** فقط في هذه الحالة. |
| لا يمكنك مراجعة فاتورة أدخلتها أو أبلغت عنها بنفسك | يراجعها مشرف آخر. |
| لم يُحدد لك قاطع للعمل الميداني | راجع الإدارة التقنية. |
| الموافقة من صلاحية الموارد البشرية فقط | الإجازات للاطلاع فقط في بوابتك. |

## القواعد

1. **العدّ أعمى**: عُدّ الأوراق أولاً، ولا تحاول معرفة المبلغ المتوقع قبل الإرسال.
2. لا تُعِد العدّ بعد إغلاق الصندوق. عالج الفرق من زر **معالجة الفرق**.
3. لا تودع النقد في المصرف. التسليم يكون لقسم المالية في المقر فقط.
4. لا توافق على تقدير أو فاتورة سابقة دون النظر إلى الصورة.
5. عند الجباية بنفسك: لا تكتب رمزاً لم يقرأه المواطن، ولا تأخذ أكثر من المبلغ.
6. لا تقرر الإجازات. أنت تطّلع عليها فقط.
