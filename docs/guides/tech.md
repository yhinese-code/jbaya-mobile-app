# دليل الإدارة التقنية

## لمن هذا الدليل

لمسؤول **لوحة التقنية**: اعتماد الأجهزة، الجلسات، الحسابات، الإعدادات والمعادلات، الصلاحيات، القواطع والتعرفة،
واتساب، مكافحة التلاعب، وسجل التدقيق.

## أول دخول

1. **ادخل إلى حساب الإدارة التقنية أولاً** قبل أي حساب آخر. أول جهاز يدخل إلى هذا الحساب يُعتمد تلقائياً.
2. اكتب **رقم الموظف (ID)** و**كلمة المرور** ثم اضغط **تسجيل الدخول**.
3. أي جهاز آخر لك يحتاج موافقة من تبويب **الأجهزة** على جهاز معتمد.
4. يُسجَّل خروج الجميع، وأنت منهم، **كل يوم عند منتصف الليل**.

## أقسام البوابة

| القسم | الغرض |
|---|---|
| **نظرة عامة** | أجهزة بانتظار الموافقة، جلسات فعّالة، متصلون الآن، محاولات مشاركة جهاز، المفاتيح العامة، أوضاع النظام، الحسابات حسب الدور. |
| **الأجهزة** | طلبات الأجهزة: **موافقة**، **رفض**، **إلغاء الاعتماد**. |
| **الجلسات** | الجلسات الفعّالة وزر **إنهاء**. |
| **الحسابات** | **موظف جديد**، **تعديل**، **صلاحيات شخصية**، **إيقاف الحساب**، **إعادة تفعيل**، **تغيير كلمة المرور**، **إنهاء كل الجلسات**. |
| **الإعدادات والمعادلات** | كل إعداد ومعادلة حسب المجموعة (المال والمعادلات، النقد، الفوترة، الميدان، الرموز، مكافحة التلاعب، الموارد البشرية والضرائب، الأداء، الدخول والأجهزة، المفاتيح، واتساب)، مع **السجل**. |
| **الصلاحيات** | إظهار أو إخفاء كل قسم لكل دور. الإخفاء يمنع الوصول في الواجهة والخادم. |
| **القواطع والتعرفة** | **قاطع جديد**، الحدود، المفاتيح لكل قاطع، و**التعرفة** لكل فئة. |
| **واتساب** | وضع الإرسال، الربط بحساب ميتا، الكلفة، القوالب المعتمدة، آخر الرسائل، و**محاكاة رسالة مواطن (للتجربة)**. |
| **مكافحة التلاعب** | أرقام مواطنين على منازل كثيرة، أشخاص بأحداث مشبوهة، مشاكل الاتصال العشوائي. |
| **سجل التدقيق** | البحث في كل الإجراءات، و**فحص سلامة السجل**. |
| **صحة النظام** | حالة قاعدة البيانات، واتساب، تتبع المواقع، التخزين. |

## المهام اليومية

### 1. اعتماد الأجهزة
1. افتح **الأجهزة** (أو اضغط **مراجعة** في **نظرة عامة**).
2. تأكد هاتفياً من الموظف: يقرأ لك **رقم الموظف** و**رمز الجهاز** الظاهرين على شاشته.
3. إذا تطابقا اضغط **موافقة**. الموافقة مرة واحدة، والجهاز يُربط بهذا الحساب فقط.
4. إذا ظهر **تجاوز حد الأجهزة** يمكنك الموافقة مع إلغاء اعتماد أقدم جهاز لهذا الموظف.
5. للطلب المشبوه اضغط **رفض** واكتب **سبب الرفض**. للهاتف المفقود اضغط **إلغاء الاعتماد**.

### 2. الحسابات والجلسات
1. لإنشاء حساب افتح **الحسابات** واضغط **موظف جديد**: رقم الموظف، الاسم، **الدور**، كلمة المرور، **رمز القاطع**، **رقم المشرف**.
2. لنسيان كلمة المرور اضغط **تغيير كلمة المرور**. تُنهى كل جلسات الموظف بعد التغيير.
3. لإيقاف موظف اضغط **إيقاف الحساب** واكتب **سبب الإيقاف**. تُنهى جلساته فوراً.
4. تغيير الدور يُنهي جلسات الموظف. لا يتغير دور موظف لديه نقد غير مسلَّم.

### 3. الإعدادات والمعادلات
1. افتح **الإعدادات والمعادلات**، واختر الإعداد، واضغط **تعديل**.
2. أدخل القيمة ضمن الحدود، واكتب **سبب التغيير (اختياري)**، ثم **حفظ**. التغيير يُطبَّق خلال ثوانٍ ويُسجَّل.
3. للعودة اضغط **إرجاع للافتراضي**.
4. فعّل **يغيّره المالك** للإعدادات التي يُسمح للمالك بتغييرها بنفسه.
5. **المفاتيح** توقف الجباية، أو التسجيل، أو الرمز الرئيسي، أو الفواتير التقديرية للجميع. **وضع الصيانة (قراءة فقط)** يمنع أي حفظ.

### 4. الصلاحيات والقواطع
1. في **الصلاحيات** أظهر أو أخفِ الأقسام لكل دور. قد يحتاج الموظف لإعادة الدخول حتى يتغير ما يراه.
2. للاستثناء لشخص واحد استعمل **صلاحيات شخصية** في **الحسابات**: **افتراضي** / **مسموح** / **ممنوع**.
3. في **القواطع والتعرفة** حدّد حدود القاطع (نقطة **lat,lng** في كل سطر، 3 نقاط على الأقل). الحدود تمنع التسجيل خارج القاطع.
4. تعديل **التعرفة** يُطبَّق على الفواتير الجديدة فقط.

### 5. واتساب
1. افتح **واتساب** وتأكد من **وضع الإرسال**: **إرسال فعلي** في العمل الحقيقي.
2. إذا ظهر **الوضع «إرسال فعلي» لكن الحساب غير مربوط** فالرسائل ستفشل حتى يُضاف رمز الوصول ورقم الإرسال.
3. في **الوضع التجريبي** فقط: استعمل **محاكاة رسالة مواطن (للتجربة)**. اكتب **رقم هاتف المواطن** و**نص الرسالة** ثم **إرسال المحاكاة**، فيتصرف النظام كأن المواطن راسل رقم الشركة. راجع **ما فعله النظام**.
4. نص القوالب معتمد من ميتا حرفياً. تغيير الصياغة يحتاج قالباً جديداً تعتمده ميتا.

### 6. المراقبة
1. افتح **مكافحة التلاعب**: الأرقام المكررة على منازل كثيرة، والأحداث المشبوهة (رمز أُدخل بسرعة، رقم موظف كمواطن، مشاركة جهاز، الرمز الرئيسي، إنكار الدفع).
2. افتح **سجل التدقيق** واضغط **فحص سلامة السجل**. النتيجة الصحيحة: **السجل سليم**.

## عند حدوث مشكلة

| الرسالة أو الحالة | المعنى وما تفعله |
|---|---|
| تجاوز حد الأجهزة | الموظف وصل للحد. وافق مع استبدال الجهاز الأقدم، أو ارفض. |
| هذا الجهاز مرتبط بحساب آخر | محاولة مشاركة جهاز. تُسجَّل في مكافحة التلاعب. |
| يمكن رفض الطلبات المعلقة فقط | للجهاز المعتمد استعمل **إلغاء الاعتماد**. |
| لدى الموظف نقد لم يُسلَّم بعد | تتم مطابقته أولاً ثم يُغيَّر دوره. |
| لا يمكنك إيقاف حسابك / لا يمكنك تغيير دورك بنفسك | يجب أن يتم من حساب تقني آخر. |
| رمز القاطع مستخدم مسبقاً | اختر رمزاً آخر. |
| الحدود تحتاج 3 نقاط على الأقل | أضف نقاطاً. |
| تم اكتشاف تعديل في السجل | السلسلة مكسورة عند سجل معين. أبلغ المالك فوراً، ولا تعدّل قاعدة البيانات. |
| المنظومة في وضع الصيانة حالياً (قراءة فقط) | أوقف **وضع الصيانة** عند الانتهاء. |

## القواعد

1. لا توافق على جهاز قبل أن تتأكد من الموظف ومن **رمز الجهاز**.
2. جهاز واحد لكل حساب ميداني، ولا يُستخدم جهاز لأكثر من حساب.
3. لا تغيّر إعداداً مالياً أو معادلة دون طلب مكتوب، واكتب السبب دائماً.
4. لا تترك واتساب في الوضع التجريبي أثناء العمل الحقيقي. المحاكاة للتجربة فقط.
5. لا تعطِ نفسك أو غيرك صلاحيات أكثر من الحاجة.
